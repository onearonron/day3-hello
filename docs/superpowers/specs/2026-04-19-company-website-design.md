# 회사 소개 정적 웹사이트 설계

## 개요

부드럽고 친근한 느낌의 회사 소개 싱글 페이지 웹사이트. HTML + 순수 CSS로 구현하며, 서비스 소개와 연락처 섹션을 포함한다.

## 파일 구조

```
day3/
├── index.html      # 메인 페이지 (모든 섹션 포함)
├── style.css       # 스타일시트
└── images/         # 이미지 에셋 (필요시)
```

## 페이지 레이아웃

```
┌─────────────────────────────┐
│         헤더 (네비)          │  로고 + 내비게이션 링크
├─────────────────────────────┤
│     서비스 소개 섹션         │  카드 형태로 서비스 나열
│  ┌─────┐ ┌─────┐ ┌─────┐   │
│  │서비스1│ │서비스2│ │서비스3│   │
│  └─────┘ └─────┘ └─────┘   │
├─────────────────────────────┤
│       연락처 섹션           │  회사 정보 + 연락 방법
├─────────────────────────────┤
│          푸터               │  저작권, 간단한 정보
└─────────────────────────────┘
```

## 섹션별 상세

### 헤더 (네비게이션)

- 좌측: 회사 로고 (텍스트)
- 우측: 내비게이션 링크 (서비스 소개, 연락처)
- 스크롤 시 고정 (sticky)
- 모바일에서는 간소화

### 서비스 소개 섹션

- 섹션 제목 ("우리의 서비스")
- 카드 형태로 3개 서비스 나열 (Flexbox 그리드)
- 각 카드: 아이콘 영역, 서비스명, 간단한 설명
- 둥근 모서리, 부드러운 그림자
- 모바일에서는 세로 스택

### 연락처 섹션

- 섹션 제목 ("联系我们" / "연락처")
- 회사 이름, 주소, 전화번호, 이메일 정보
- 깔끔한 아이콘 + 텍스트 조합

### 푸터

- 저작권 정보
- 심플한 한 줄 구성

## 디자인 시스템

### 색상 팔레트

- 배경: #FAFAFA (밝은 웜 그레이)
- 카드 배경: #FFFFFF
- 주 색상: #5B8DEF (소프트 블루)
- 포인트: #FF8A80 (소프트 코럴)
- 텍스트: #2D3748 (다크 그레이)
- 서브 텍스트: #718096 (미디엄 그레이)

### 타이포그래피

- 시스템 폰트 스택 (한국어 최적화): 'Pretendard', '-apple-system', 'Segoe UI', sans-serif
- 제목: 2rem, 굵음
- 본문: 1rem, 보통

### 공통 스타일

- 카드 border-radius: 16px
- 카드 box-shadow: 부드러운 그림자 (rgba 0.05~0.1)
- 섹션 여백: 상하 80px, 좌우 20px (최대 너비 1200px)

## 기술 스펙

- HTML5 시맨틱 태그 사용 (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`)
- 순수 CSS: CSS 변수로 색상 관리, Flexbox/Grid 레이아웃
- 반응형: 768px 브레이크포인트 (모바일/데스크탑)
- JavaScript 불필요
- 한국어 콘텐츠 (`lang="ko"`, `<meta charset="UTF-8">`)
